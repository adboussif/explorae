# EXPLORAE — Automated Scoring and Integration of Protein–Protein Interaction Metrics

EXPLORAE is a Python-based pipeline designed to compute, aggregate, and export multiple structural confidence, biophysical, and energy-based metrics from AlphaFold-Multimer protein–protein interaction predictions.

The tool scans interaction-specific model folders generated by AlphaFold-Multimer, computes interface confidence and interaction metrics (ipSAE, pDockQ2, ipTM, pTM, PRODIGY predictions, and Rosetta interface energies), and consolidates all results into a single Excel or CSV file for downstream analysis and modeling.

---

## Overview

EXPLORAE automates the post-processing of AlphaFold-Multimer outputs by:
- parsing ranking and confidence files,
- computing interface-specific confidence scores,
- running external interaction scoring tools,
- normalizing and exporting all metrics in a unified, analysis-ready format.

The pipeline is designed for large-scale interaction screening, benchmarking, and machine-learning–driven binder prioritization (notebooks folder).

## Metric Definitions and Interpretation

### AlphaFold Confidence Metrics

- **ipSAE**  
  Interface-specific transformation of the Predicted Aligned Error (PAE) matrix.  
  PAE values are converted using a PTM-like transformation into a 0–1 confidence per residue pair, then aggregated over the interface.  
  Higher values indicate higher interface confidence.

- **pDockQ2**  
  Empirical interface correctness score combining local pLDDT confidence and transformed PAE values, mapped through a logistic regression model.

- **ipTM / pTM**  
  TM-score–like metrics output by AlphaFold-Multimer and extracted from `ranking_debug.json`.  
  `ipTM+pTM` is used by AlphaFold for model ranking.

These metrics are confidence-based and derived directly from AlphaFold’s internal uncertainty estimates.

---

### PRODIGY Metrics

- **ΔG (internal)**  
  Empirical binding free energy estimated by PRODIGY using a linear model based on interface contacts and residue composition (kcal/mol).

- **Kd**  
  Dissociation constant derived from ΔG using:  
  `Kd = exp(ΔG / (R · T))`  
  where `R` is the gas constant (kcal·mol⁻¹·K⁻¹) and `T` the temperature (K).

PRODIGY scores are empirical and best suited for comparative analyses.

---

### Rosetta (PyRosetta) Metrics

- **dG_cross**  
  Interface energy computed using `InterfaceAnalyzerMover` (Rosetta Energy Units).

- **dSASA_int**  
  Buried solvent-accessible surface area upon binding (Å²).

- **dG_SASA_ratio**  
  Interface energy normalized by buried surface area:  
  `dG_SASA_ratio = dG_cross / dSASA_int`

Rosetta energies are empirical and primarily meaningful in relative comparisons within the same dataset.

## Installation

```bash
git clone https://github.com/adboussif/explorae.git
cd explorae
python3 -m venv .venv
source .venv/bin/activate
./install_explorae.sh


  ## Usage de base

  ```bash
  python ./src/explorae.py ./test_af2.xlsx ./test/af2
  python ./src/explorae.py --af3 ./test_af3.xlsx ./test/af3  
  ```


What the script does for AF2 with test dataset :
- Iterates over interaction-specific subfolders in ./interactions
- Identifies the top-ranked AlphaFold model via ranking_debug.json
- Extracts ipTM and pTM scores
- Computes ipSAE and pDockQ2
- Runs PRODIGY and parses its outputs
- Runs PyRosetta interface analysis
- Creates columns in the Excel/CSV file

The script does nearly the same for AF3 (without the Energy scores) with AF3 outputs (mmCIF + confidences.json + summary_confidences.json).

  ---

  ## Options (principales)

  | Option | Usage |
  |--------|-------|
  | `--pae` | seuil PAE (Å) pour ipSAE (par défaut `10`) |
  | `--dist` | cutoff distance (Å) pour ipSAE (par défaut `10`) |
  | `--id-col` | nom de la colonne ID dans l'Excel (par défaut `jobs`) |
  | `--sheet` | onglet Excel (index ou nom, par défaut `0`) |
  | `--af3`   | Compute Alphafold based scores with AlphaFold3 outputs (mmCIF + confidences.json + summary_confidences.json)|

  Exemple :
  ```bash
  python ./src/explorae.py test.xlsx ./interactions --pae 12 --dist 8 --id-col jobs --sheet 0
  ```
